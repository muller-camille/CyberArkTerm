Les applications distantes PSM (RemoteApp, par exemple PSM-SSH) s'affichent dans l'onglet de CyberArkTerm, et non plus dans des fenêtres à part.

### Nouveauté : application distante dans l'onglet

- La fenêtre principale de l'application prend toute la place de l'onglet et suit sa taille.
- Ses menus et boîtes de dialogue s'ouvrent au-dessus de l'onglet, là où le serveur les place.
- Le clavier va à l'application quand vous sélectionnez l'onglet ou cliquez dedans.
- Changer d'onglet la masque puis la réaffiche. « Déconnecter » et « Reconnecter » fonctionnent comme avant.
- Le PSM l'accepte : la connexion reste en mode application distante. Seule sa fenêtre est placée dans l'onglet de ce poste.
- C'est le comportement par défaut. Pour revenir aux fenêtres à part, décochez « Afficher dans l'onglet la fenêtre des applications distantes » dans les Paramètres.

**Comment ça marche :**
- Le contrôle Bureau à distance de Windows crée les fenêtres de l'application dans CyberArkTerm et signale chacune d'elles.
- La fenêtre principale est rattachée à l'onglet. Le contrôle continue de transmettre sa position au serveur : les clics arrivent au bon endroit.
- Rattachée à l'onglet, la fenêtre n'est plus « active » pour Windows. CyberArkTerm le signale donc lui-même au serveur, sinon la frappe n'arriverait pas.

**Limites :**
- La barre de titre dessinée par le serveur (titre, réduire, agrandir, fermer) reste visible en haut de l'onglet. Si le serveur déplace ou réduit la fenêtre, elle est remise en place.
- Les fenêtres secondaires (boîtes de dialogue) restent à part, au-dessus de l'onglet.

### Paramètres

- Nouveau : « Afficher dans l'onglet la fenêtre des applications distantes », coché par défaut.
- Renommé : « Ouvrir plutôt les applications distantes PSM comme un bureau », décoché par défaut. Son bouton de secours devient « Ouvrir en application distante ».

### Vérifications

- Sur un vrai serveur Windows (CI), avec le Bloc-notes en application distante :
  - la fenêtre occupe exactement l'onglet, et le suit quand on le redimensionne ;
  - le texte tapé arrive dans l'application, après la sélection de l'onglet comme après un clic (relu dans le presse-papiers redirigé) ;
  - le menu contextuel s'ouvre sous la souris ;
  - la fenêtre est retirée de l'onglet à la déconnexion.
- Tests du cœur (404) et des sessions réelles (7).
- À confirmer sur votre poste : PSM-SSH sur votre PSM. Le journal de débogage note chaque fenêtre de l'application et celle placée dans l'onglet (lignes `rdp`).

### Installation

Téléchargez `CyberArkTerm-0.6.0-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ». Depuis une version précédente, remplacez simplement l'exécutable : vos paramètres sont conservés.
