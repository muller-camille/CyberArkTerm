Un composant PSM par défaut pour les comptes Windows.

### Composant PSM des comptes Windows

- **Paramètres › CyberArk › Composants PSM** : « Comptes Windows », par exemple `WIN-PSM` quand votre PVWA ne nomme pas son composant `PSM-RDP`.
- Il s'applique aux comptes Windows (domaine ou locaux) qui n'ont pas de composant mémorisé pour leur plateforme. Un composant mémorisé reste prioritaire. Vide : `PSM-RDP`, comme avant.
- Il est proposé en tête des listes de composants (« Connexion avancée », propriétés d'un serveur de « Mes serveurs »).
- Le nom est vérifié : lettres, chiffres, « - », « _ » et « . ».

### Divers

- Infobulle « Machine cible » de « Connexion avancée » : obligatoire pour un compte de domaine.
