Un fichier pour partager la configuration de l'équipe, et un composant PSM par défaut pour les comptes Windows.

### Environnement partagé

- **Fichier `CyberArkTerm.env.json`** : la configuration de l'équipe pour un coffre CyberArk, sans rien de personnel ni aucun mot de passe. Il contient :
  - l'adresse du PVWA et la méthode de connexion ;
  - le PSMP par défaut et les PSMP par domaine ;
  - le composant des comptes Windows et les composants par plateforme ;
  - les listes partagées et les clés des PSMP ;
  - quelques options : maintien de la session PVWA, SSH intégré, recherche de mise à jour, protocole d'envoi.
- **Exporter** : bouton « Paramètres » → « Exporter l'environnement… ».
- **À côté de l'exécutable** : posé à côté de `CyberArkTerm.exe` (par exemple dans le même zip), le fichier est proposé au démarrage, avant l'écran de connexion, quand il est nouveau ou a changé.
- **Importer** : bouton « Paramètres » → « Importer un environnement… », ou lien « Importer un environnement… » sur l'écran de connexion.
- **Fichier central** : Paramètres › Général › « Fichier central » (sur un partage réseau, ou indiqué dans l'environnement lui-même). Il est relu à chaque démarrage : une modification faite par l'équipe est proposée à chacun.
- **Sécurité** :
  - chaque fois, une fenêtre montre les changements (« ancienne valeur → nouvelle valeur ») et l'empreinte SHA-256 du fichier, avec « Ne pas appliquer » par défaut ;
  - si l'adresse du PVWA ou d'un PSMP change, ou si une clé de serveur est ajoutée, il faut cocher « J'ai vérifié… » avant d'appliquer ;
  - une clé de serveur déjà acceptée n'est jamais remplacée par un fichier ;
  - un fichier invalide (adresse en http, nom incorrect…) est refusé en entier ;
  - les champs inconnus, un mot de passe ajouté à la main par exemple, sont ignorés.
- Votre identifiant, « Mes serveurs » et vos sessions récentes ne sont jamais touchés. Les listes partagées s'ajoutent sans retirer les vôtres.

### Composant PSM des comptes Windows

- **Paramètres › CyberArk › Composants PSM** : « Comptes Windows », par exemple `WIN-PSM` quand votre PVWA ne nomme pas son composant `PSM-RDP`.
- Il s'applique aux comptes Windows (domaine ou locaux) sans composant mémorisé pour leur plateforme. Un composant mémorisé reste prioritaire. Vide : `PSM-RDP`, comme avant.
- Il est proposé en tête des listes de composants. Son nom est vérifié.

### Divers

- Infobulle « Machine cible » de « Connexion avancée » : obligatoire pour un compte de domaine.
