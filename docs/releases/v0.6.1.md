### Corrections

**Composants PSM nommés par votre PVWA**
- Un PVWA peut donner à ses composants de connexion d'autres noms que les noms habituels de CyberArk. Par exemple `WIN-PSM` au lieu de `PSM-RDP` pour une plateforme de comptes de domaine.
- Jusqu'ici, la liste ne proposait que les noms habituels (PSM-RDP, PSM-SSH…).
- Elle propose maintenant, dans cet ordre et sans doublon :
  1. le composant mémorisé pour la plateforme du compte ;
  2. les composants déjà utilisés (mémorisés, serveurs de « Courants », connexions récentes) ;
  3. les noms habituels.
- Un composant saisi une fois revient donc dans la liste, en tête pour sa plateforme.

**Erreur `EPVWA093E Failed to get the relevant connection component`**
- Le PVWA renvoie cette erreur quand le composant demandé n'existe pas pour la plateforme du compte.
- La fenêtre de connexion se rouvre alors sur le champ « Composant », avec une explication : où trouver le bon nom (le bouton « Connect » du PVWA, ou le nom après `/c` dans une commande `psm /u … /a … /c …`).
- « Mémoriser ce composant pour la plateforme » est coché d'avance.
