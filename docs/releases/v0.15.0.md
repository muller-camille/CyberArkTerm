Comparer un fichier avec un autre serveur : un explorateur de ce serveur pour choisir le fichier, au lieu de taper son chemin.

### Nouveautés

**Comparer avec un autre serveur**
- **Parcourir…** : à côté du chemin, dans la fenêtre « Comparer avec… », ouvre un explorateur du serveur choisi.
- **Même chemin par défaut** : l'explorateur s'ouvre sur le dossier du fichier comparé, fichier présélectionné. Si ce dossier n'existe pas sur l'autre serveur, il s'ouvre sur le plus proche dossier parent qui existe, sinon sur le dossier personnel du compte.
- **Navigation** : double-clic ou Entrée sur un dossier pour y entrer, « .. », le bouton ↑ ou Retour arrière pour remonter. On peut aussi taper un chemin de dossier ou de fichier, puis Entrée (`~` est le dossier personnel). Les fichiers cachés sont affichables.
- **Choix** : double-clic sur un fichier ou « Choisir ». Le fichier choisi remplace le chemin de la fenêtre « Comparer avec… ».
- **Onglet Fichiers inchangé** : les dossiers sont lus par la connexion SFTP de ce serveur sans changer le dossier affiché dans son onglet Fichiers. Rien n'est lancé sur le serveur.

**Idées** : IDEAS.md compte de nouvelles pistes :
- reprendre un envoi interrompu ;
- comparer et synchroniser un dossier ;
- bilan de livraison exportable ;
- notification en fin de transfert ;
- signets de dossiers ;
- recherche de fichiers ;
- tester l'accès d'un serveur au PSMP ;
- retenir un refus SCP pour l'onglet.

### Vérifications

- **Contre un vrai serveur OpenSSH** :
  - lecture de dossiers sans changer le dossier courant de l'onglet Fichiers ;
  - fichiers cachés affichés seulement à la demande ;
  - dossier absent et dossier interdit signalés (« chemin introuvable », « permission refusée »).
- **Application sous Windows (émulé)**, en français, anglais et italien :
  - fenêtre « Comparer avec… » avec le nouveau bouton ;
  - explorateur ouvert sur le même dossier, fichier présélectionné.
- **Tests** : explorateur (même chemin, plus proche parent, « .. », chemin tapé, choix d'un fichier, `~`), dossiers parents d'un chemin ; tests du cœur (532).

### Installation

Téléchargez `CyberArkTerm-0.15.0-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ». Depuis une version précédente, remplacez simplement l'exécutable : vos paramètres sont conservés.

Comparing a file with another server: an explorer of that server to choose the file, instead of typing its path.

**Compare with another server**
- **Browse…**: next to the path, in the "Compare with…" window, opens an explorer of the chosen server.
- **Same path by default**: the explorer opens on the folder of the compared file, with the file preselected. If that folder does not exist on the other server, it opens on the closest existing parent folder, otherwise on the account's home folder.
- **Navigation**: double-click or Enter on a folder to enter it, "..", the ↑ button or Backspace to go up. A folder or file path can also be typed, then Enter (`~` is the home folder). Hidden files can be shown.
- **Choice**: double-click a file or "Choose". The chosen file replaces the path of the "Compare with…" window.
- **Files tab unchanged**: folders are read over that server's SFTP connection without changing the folder shown in its Files tab. Nothing runs on the server.

**Ideas**: IDEAS.md has new items: resume an interrupted upload, compare and synchronize a folder, exportable delivery report, notification at the end of transfers, folder bookmarks, file search, test a server's access through the PSMP, remember an SCP refusal for the tab.

Confrontare un file con un altro server: un esploratore di quel server per scegliere il file, invece di digitarne il percorso.

**Confronta con un altro server**
- **Sfoglia…**: accanto al percorso, nella finestra «Confronta con…», apre un esploratore del server scelto.
- **Stesso percorso per impostazione predefinita**: l'esploratore si apre sulla cartella del file confrontato, con il file preselezionato. Se quella cartella non esiste sull'altro server, si apre sulla cartella superiore più vicina che esiste, altrimenti sulla cartella personale dell'account.
- **Navigazione**: doppio clic o Invio su una cartella per entrarvi, «..», il pulsante ↑ o Backspace per risalire. Si può anche digitare il percorso di una cartella o di un file, poi Invio (`~` è la cartella personale). I file nascosti si possono mostrare.
- **Scelta**: doppio clic su un file o «Scegli». Il file scelto sostituisce il percorso della finestra «Confronta con…».
- **Scheda File invariata**: le cartelle vengono lette tramite la connessione SFTP di quel server senza cambiare la cartella mostrata nella sua scheda File. Nulla viene eseguito sul server.

**Idee**: IDEAS.md contiene nuove piste: riprendere un invio interrotto, confrontare e sincronizzare una cartella, riepilogo di consegna esportabile, notifica a fine trasferimenti, segnalibri di cartelle, ricerca di file, testare l'accesso di un server tramite il PSMP, ricordare un rifiuto SCP per la scheda.

**Verifiche**: contro un vero server OpenSSH (cartelle lette senza cambiare la cartella corrente della scheda File, file nascosti solo su richiesta, cartelle assenti e vietate segnalate); l'applicazione sotto Windows emulato in italiano, francese e inglese (finestra «Confronta con…» con il nuovo pulsante, esploratore aperto sulla stessa cartella con il file preselezionato); test dell'esploratore (stesso percorso, cartella superiore più vicina, «..», percorso digitato, scelta di un file, `~`) e delle cartelle superiori di un percorso; 532 test del nucleo.
