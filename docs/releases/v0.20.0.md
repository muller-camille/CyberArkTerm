Reprise des sessions d'un autre logiciel dans « Mes serveurs », pour passer à ZillaTerm sans rien retaper et ne plus se connecter aux serveurs en direct.

### Importer les sessions d'un autre logiciel

- **Où** : bouton en haut de « Mes serveurs » (icône terminal et bouclier), ou bouton « Paramètres » → « Importer les sessions d'un autre logiciel… ». Les comptes du PVWA doivent être chargés ; absent en accès d'urgence.
- **Sources** :
  - PuTTY, KiTTY et WinSCP, lus directement dans votre registre Windows, ou dans un export du registre (`.reg`) ;
  - KiTTY portable (dossier `Sessions`) et `WinSCP.ini` ;
  - fichier `.mxtsessions` ou `.ini` de sessions ;
  - mRemoteNG (`confCons.xml`, non chiffré en entier) et Remote Desktop Connection Manager (`.rdg`) ;
  - SecureCRT (dossier de configuration ou export XML) ;
  - OpenSSH (fichier `config`) et dossier de fichiers `.rdp`.
- **Même arborescence** : les dossiers de l'autre logiciel sont recréés sous « Importés » (modifiable ; vide : à la racine), chaque serveur gardant son nom.
- **Compte du PVWA de chaque serveur** :
  - compte du serveur lui-même (même nom, ou nom court et nom complet), avec le même utilisateur et un type adapté (Windows pour le bureau à distance, Unix ou réseau pour SSH) ;
  - à défaut, compte de domaine du même utilisateur autorisé sur ce serveur, qui devient sa machine cible ;
  - plusieurs comptes possibles : le plus probable est choisi, un autre peut l'être dans la liste.
- **Sessions qui passaient déjà par CyberArk** : une connexion via le PSMP (`coffre@cible@serveur@psmp`) ou via PSM (`psm /u … /a … /c …` d'un fichier `.rdp`) est décodée ; le composant PSM est gardé.
- **Toujours via CyberArk** : bureau à distance par PSM ; SSH et fichiers via le PSMP (fichiers seuls pour une plateforme « SFTP »), sinon par PSM ; jamais de connexion directe.
- **Résultat** : aperçu avant l'import (prêt, à vérifier, sans compte, non pris en charge, déjà présent), puis résultat de chaque serveur : « Importé », ou « Non importé » avec la raison (aucun compte dans le PVWA, connexion VNC, FTP ou série non prise en charge…). « Exporter le résultat… » l'enregistre en CSV : la liste des serveurs à faire ajouter dans CyberArk.
- **Sécurité** : aucun mot de passe n'est lu, ni dans le registre ni dans les fichiers ; seuls le serveur, le port, le protocole, l'utilisateur et le dossier le sont. Une fois la migration faite, supprimez les mots de passe gardés par l'autre logiciel.
