Les sessions récentes s'ajoutent aux serveurs courants d'un clic droit, l'onglet « Courants » a une recherche, et l'onglet « Tous les comptes » disparaît.

### Nouveautés

**Ajouter une session récente aux serveurs courants**
- Clic droit sur une ligne de « Sessions récentes » (accueil) : « Se connecter » ou « Ajouter aux serveurs courants », puis la racine, un dossier existant ou un nouveau dossier.
- Le serveur ajouté reprend la configuration de la session : nom affiché, type de connexion (PSM ou SSH), composant PSM et machine cible utilisés.
- Si le compte n'est plus disponible (supprimé, droits retirés, autre PVWA, accès d'urgence), l'ajout est grisé avec une explication.

**Recherche dans l'onglet « Courants »**
- Un champ « Rechercher un serveur… » en haut de l'onglet filtre les serveurs. Il cherche dans le nom, le serveur, l'utilisateur, le dossier, le type de connexion, le composant, la machine cible, la plateforme et le safe. Plusieurs mots sont possibles (`prod web`).
- Il cherche aussi dans les entrées des coffres KeePass déverrouillés : titre, utilisateur, URL, dossier, étiquettes, serveur, protocole. Les notes ne sont pas parcourues, et les coffres verrouillés sont masqués pendant la recherche.
- Les dossiers des résultats sont dépliés. Une fois la recherche effacée, les dossiers que vous aviez repliés le restent.
- `Entrée` ou `↓` sélectionne le premier résultat (`Entrée` une seconde fois pour se connecter), `Échap` efface. Dans l'onglet « Courants », `Ctrl+F` place le curseur dans ce champ.

### Changements

**Onglet « Tous les comptes » retiré**
- Il présentait les mêmes comptes que l'onglet « Disponibles ».
- Le bouton « Exporter » enregistre toujours en CSV les comptes affichés dans « Disponibles », filtrés par la recherche.
- La copie de plusieurs comptes à la fois, possible seulement depuis ce tableau, disparaît : « Copier le serveur » et les autres copies portent sur le compte sélectionné.

### Vérifications

- Tests du cœur (400), dont l'ajout d'une session récente avec sa configuration et la recherche (serveurs, dossiers, entrées KeePass).
- Tests de l'application et session Bureau à distance réelle sur Windows (GitHub Actions).

### Installation

Téléchargez `CyberArkTerm-0.7.0-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ». Depuis une version précédente, remplacez simplement l'exécutable : vos paramètres sont conservés.
