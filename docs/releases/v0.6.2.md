Les sessions PSM s'ouvrent de nouveau dans « Connexion Bureau à distance » de Windows, les comptes Unix s'ouvrent en SSH par défaut, et le menu « Paramètres » est simplifié.

### Changements

**Sessions PSM dans « Connexion Bureau à distance »**
- Le fichier .rdp fourni par le PVWA est ouvert tel quel par `mstsc`, dans sa propre fenêtre, comme depuis le bouton « Connect » du PVWA.
- Les versions 0.4 à 0.6 affichaient ces sessions dans un onglet. Les PSM qui n'acceptent le jeton qu'en application distante (RemoteApp, `||PSMInitSession`) s'y comportaient mal : taille de fenêtre, souris inopérante, fenêtres qui sortaient de l'onglet.
- L'affichage RemoteApp intégré est donc retiré : ancrage dans l'onglet, conversion en bureau, retour automatique en fenêtres séparées et bouton « Ouvrir en application distante ».
- Le fichier .rdp est écrit dans `%TEMP%\CyberArkTerm` pour `mstsc`, qui vérifie sa signature, puis supprimé au bout de 60 secondes.
- Les connexions RDP directes depuis une entrée KeePass restent dans un onglet.

**Comptes Unix en SSH par défaut**
- Si une adresse PSMP est renseignée, le double-clic sur un compte Unix ouvre une session SSH via le PSMP.
- Le PSM reste disponible pour ces comptes dans « Connexion avancée ».

**Menu « Paramètres » simplifié**
- La section « Bureau à distance (RDP) » et la case « Double-clic sur un compte Unix : se connecter en SSH via PSMP » disparaissent : elles n'ont plus d'objet.
- Un fichier de paramètres d'une version précédente se charge normalement ; les options retirées sont ignorées.

### Vérifications

- Tests du cœur (397).
- Tests de l'application et session Bureau à distance réelle dans un onglet sur Windows (GitHub Actions).

### Installation

Téléchargez `CyberArkTerm-0.6.2-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ». Depuis une version précédente, remplacez simplement l'exécutable : vos paramètres sont conservés.
