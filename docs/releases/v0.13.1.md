### Corrections

### Améliorations

**Historique des transferts** : bouton « Historique » dans la barre d'outils, à gauche de « Paramètres », au lieu du petit bouton horloge dans le coin de l'onglet Fichiers. Il s'ouvre même sans session.

**Archive .tar.gz : extraction sur tous les Unix** (Red Hat 5 à 9, HP-UX 11.11 et 11.31, Solaris, AIX…)
- L'archive est maintenant au format tar POSIX standard (ustar), lu par tous les tar. Le format GNU utilisé jusqu'ici n'est bien lu que par tar GNU (Linux) : un nom long y était illisible pour le tar de HP-UX, Solaris ou AIX.

- Un nom de fichier de plus de 100 caractères ou un fichier de plus de 8 Go ne tient pas dans ce format : l'archive n'est pas proposée, les fichiers partent un par un, avec un message.
