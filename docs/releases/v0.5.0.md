Les sessions Bureau à distance ne figent plus l'application, un menu sur les onglets, le téléchargement en glissant vers l'Explorateur, et un correctif de sécurité. Mise à jour recommandée.

### Sécurité

- **Téléchargement de plusieurs fichiers** : le bouton « Télécharger » plaçait le nom Unix tel quel dans le dossier choisi. Un nom comme `..\..\x` envoyé par le serveur pouvait donc écrire hors de ce dossier.
- Les noms sont maintenant rendus sûrs pour Windows :
  - `\ / : * ? " < > |` et les caractères de contrôle sont remplacés ;
  - `.`, `..` et les noms réservés (`CON`, `COM1`…) sont neutralisés ;
  - les noms sont limités à 255 caractères.
- Le chemin final est vérifié.

### Nouveautés

**Bureau à distance sur son propre thread**
- Chaque connexion Bureau à distance a son propre thread : le contrôle, sa fenêtre et ses événements y vivent, et l'interface ne l'attend jamais.
- Une déconnexion, une libération du contrôle ou un serveur qui tarde ne fige plus l'application. Avant de libérer le contrôle, sa fenêtre est retirée de l'onglet.
- Si une session ne répond plus pendant 5 s, la barre de son onglet l'indique, et le reste de l'application reste utilisable.
- Limite : Windows partage le clavier et la souris entre une fenêtre et celles qu'elle contient. Une session bloquée pour de bon peut encore retenir un clic dans sa zone.

**SSH**
- La frappe, la taille du terminal et la fermeture des connexions passent hors du thread de l'interface : un serveur ou un PSMP qui ne lit plus ne fige plus l'application.

**Menu des onglets** (clic droit sur un onglet SSH ou Bureau à distance)
- **Reconnecter** : demande confirmation si la session est ouverte.
- **Dupliquer l'onglet** : une autre session sur le même compte (même composant, même motif) ou sur la même entrée KeePass.
- **Fermer l'onglet**.
- **Fermer les autres onglets** : une seule confirmation.

**Télécharger en glissant vers l'Explorateur** (onglet Fichiers)
- Glissez des fichiers ou des dossiers de la liste vers l'Explorateur ou le bureau.
- Rien n'est téléchargé pendant le glissement. Au dépôt, une fenêtre montre la progression (Annuler l'interrompt), puis l'Explorateur copie les fichiers là où vous les avez déposés.
- Les dossiers sont pris en entier, fichiers cachés compris, jusqu'à 10 000 éléments. Les liens vers des dossiers ne sont pas suivis.
- Le dossier temporaire du téléchargement est effacé ensuite.

### Vérifications

- Tests du cœur (403) :
  - nettoyage des noms (remontée de dossiers, noms réservés, longueur, noms uniques) ;
  - description des fichiers glissés (`FileGroupDescriptorW`).
- Sur un vrai Windows de CI :
  - l'interface continue de répondre pendant que le contrôle Bureau à distance est bloqué 8 s, et elle le signale ;
  - fermer une session bloquée rend la main aussitôt ;
  - les sessions réelles s'ouvrent comme avant (bureau, application distante, fenêtres séparées) ;
  - les données glissées sont lues comme par l'Explorateur : description sans téléchargement, contenu au dépôt, téléchargé une seule fois.
- Le dépôt dans l'Explorateur lui-même est à confirmer sur votre poste.

### Installation

Téléchargez `CyberArkTerm-0.5.0-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ». Depuis une version précédente, remplacez simplement l'exécutable : vos paramètres sont conservés.
