Un PSMP par domaine de serveurs, les comptes de domaine qui demandent sur quel serveur ouvrir la session, et « Ajouter à Mes serveurs » depuis une session ouverte.

### PSMP par domaine

- **Paramètres › CyberArk** : un PSMP par défaut et une liste de PSMP (adresse, port, domaine servi, déduit de l'adresse et modifiable).
- Chaque serveur passe par le PSMP du domaine le plus proche du sien : srv01.zzz.xxx.corp.com passe par psmp.zzz.xxx.corp.com s'il est dans la liste, sinon par psmp.xxx.corp.com.
- Serveur d'aucun domaine de la liste (ou adresse IP) : PSMP par défaut ; sans lui, le seul PSMP de la liste s'il n'y en a qu'un. Sinon la connexion est refusée et la barre d'état dit pourquoi.
- Champ « Quel PSMP pour le serveur » pour vérifier avant d'enregistrer ; deux PSMP pour le même domaine sont refusés.
- Sécurité : seuls les PSMP de la liste reçoivent votre mot de passe CyberArk, jamais une adresse déduite d'un nom de serveur. La clé de chaque PSMP est vérifiée à sa première connexion.
- SSH, fichiers seuls (SFTP), SSH dans Windows Terminal et « Connexion avancée » utilisent le PSMP du serveur ; l'infobulle de l'onglet le nomme.

### Comptes de domaine

- Un compte enregistré pour son domaine (adresse `corp.local`) ouvre la fenêtre **« Choisir le serveur »** : serveurs déjà utilisés avec ce compte (sessions récentes, « Mes serveurs ») puis ses machines autorisées ; un compte limité à ses machines refuse les autres.
- **« Garder ce serveur dans « Mes serveurs » »**, avec le dossier : le serveur y est ajouté après une connexion réussie, nommé `compte@serveur`. Le choix est mémorisé ; la case disparaît si le serveur y est déjà.
- « Avancée… » ouvre la fenêtre de connexion complète avec ce serveur.
- Détection élargie : un compte Windows (hors compte local) dont l'adresse est son domaine de connexion est traité comme un compte de domaine, quel que soit le nom de sa plateforme.
- « Ajouter à Mes serveurs » d'un compte de domaine demande le serveur (facultatif : sans serveur, il est demandé à chaque connexion).

### Sessions

- **« Ajouter à Mes serveurs »** dans le menu de l'onglet et du clic droit dans le terminal : le serveur garde le type de connexion et la machine cible ; l'entrée est grisée s'il y est déjà.
- Une session SSH qui s'ouvre affiche l'onglet « Fichiers » du panneau de gauche (un panneau replié le reste).
