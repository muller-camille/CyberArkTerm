### Corrections

**File d'attente : annuler un envoi SCP**
- Annuler l'envoi en cours fermait la connexion SCP. L'envoi suivant en ouvrait une nouvelle par le PSMP ; si le serveur la refusait ou la fermait aussitôt, l'erreur « Stream has been closed » apparaissait, et la connexion inutilisable restait en mémoire : tous les envois SCP suivants de la file échouaient de la même façon.
- L'annulation arrête maintenant seulement le fichier en cours : les éléments suivants continuent sur la même connexion SCP, sans nouvelle session PSMP.
- Une connexion SCP coupée n'est plus jamais réutilisée. Si le serveur ferme le canal SCP avant le début d'un fichier, CyberArkTerm réessaie une fois, 2 secondes plus tard, sur une nouvelle connexion ; si cela échoue encore, le message l'explique (« Le serveur a fermé la connexion SCP… choisissez SFTP pour les envois dans les Paramètres ») au lieu de « Stream has been closed ».
- Le bilan de la file restait affiché moins d'une demi-seconde : la relecture du dossier après le transfert le remplaçait par « Dossiers : … fichiers : … ». Il reste maintenant affiché.
- Avec le journal de débogage activé, chaque transfert terminé, annulé ou en échec y est écrit, avec l'erreur complète.
- Un fichier envoyé par SCP prend maintenant sur le serveur la date de l'envoi, comme `scp` sans `-p` et comme un envoi SFTP (il gardait la date de modification du fichier local).

### Nouveautés

**Clic droit dans le terminal SSH** : un menu remplace le collage direct.
- Copier, Coller, Tout sélectionner (historique et écran, copiés dans le presse-papiers).
- Rechercher dans le terminal, Enregistrer le contenu du terminal.
- Effacer l'historique : oublie les lignes sorties de l'écran, sur ce poste seulement (rien n'est envoyé au serveur).
- Taille de police : agrandir, réduire, taille par défaut.
- Les actions de l'onglet : reconnecter, dupliquer, détacher dans une nouvelle fenêtre, vue parallèle, fermer.
- Fonctionne aussi dans une fenêtre détachée et dans la vue parallèle. La touche Menu du clavier ouvre le même menu.
- Pour garder le collage d'un simple clic droit : Paramètres → « Le clic droit dans le terminal colle le presse-papiers » ; Maj+clic droit ouvre alors le menu.

**Onglet Fichiers : tri par colonne**
- Cliquez sur l'en-tête Nom, Taille, Modifié ou Droits pour trier ; un second clic inverse l'ordre, une flèche dans l'en-tête l'indique.
- La taille et la date commencent par les plus gros et les plus récents (le dernier fichier de log en tête).
- Les dossiers restent en tête, « .. » tout en haut ; la sélection est gardée.
- Le tri choisi est gardé d'un dossier, d'une session et d'un lancement à l'autre.

**Sommes de contrôle dans l'Historique** : le lien « Sommes de contrôle… » de la barre d'état de l'onglet Fichiers est retiré. Les sommes SHA-256 de chaque transfert sont dans l'Historique (bouton de la barre d'outils, double-clic sur un transfert). Si un fichier transféré diffère, le détail s'ouvre toujours de lui-même.

**Icône de l'Historique** : flèches d'envoi et de téléchargement avec une horloge, au lieu d'une simple horloge (qui reste pour les connexions récentes de l'accueil). L'info-bulle mentionne les sommes SHA-256.

### Vérifications

- **Annulation et file SCP**, avec un vrai serveur OpenSSH :
  - un envoi annulé en cours, puis deux autres : une seule connexion SCP, les deux suivants terminés et vérifiés ;
  - serveur qui ferme le canal SCP une fois : nouvel essai sur une nouvelle connexion, les deux envois terminés ;
  - serveur qui le ferme deux fois de suite : message clair pour cet envoi, l'envoi suivant réussit sur une nouvelle connexion.
- **Application sous Windows (émulé)** avec un faux PSMP : menu du clic droit (éléments grisés quand ils sont sans objet : copier sans sélection, effacer sans historique, taille par défaut), effacement de l'historique, sous-menu de police, tri par taille dans les deux sens dans `/var/log` et `/etc`, flèche de tri, nouvelle icône.
- **Tests de l'application** : menu du terminal (contenu, raccourcis, actions de la session, effacement et recherche), tri de l'onglet Fichiers (ordre, flèche, sélection gardée, réglage enregistré).
- **Tests du cœur (524)** : tri par chaque colonne dans les deux sens, effacement de l'historique du terminal.

### Installation

Téléchargez `CyberArkTerm-0.14.0-win-x64.zip`, décompressez-le et lancez `CyberArkTerm.exe` (Windows 10 ou 11 x64, aucun runtime ni droit administrateur requis). L'empreinte SHA256 est dans `SHA256SUMS.txt`. L'exécutable n'est pas signé : SmartScreen peut demander « Informations complémentaires » → « Exécuter quand même ».
