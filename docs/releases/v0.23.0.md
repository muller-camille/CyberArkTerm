Filtre dans l'onglet Fichiers : ne garder que les éléments du dossier dont le nom vous intéresse, même dans un dossier de plusieurs milliers d'éléments.

### Onglet Fichiers : filtre sur le nom

- Nouveau champ sous le chemin. Il garde les éléments dont le nom contient le texte saisi (`nginx`), sans tenir compte des majuscules.
- Avec `*` et `?`, c'est un masque qui doit correspondre au nom entier : `*.log`, `app?.conf`. Plusieurs filtres séparés par `;` : `*.log;*.gz`.
- `..` reste toujours affiché pour remonter, et la barre d'état indique combien d'éléments sont affichés sur le total.
- Le tri par colonne garde le filtre ; il est vidé quand vous changez de dossier.
- Clavier :
  - `Ctrl+F` dans l'onglet Fichiers place le curseur dans le filtre (ailleurs, il cherche toujours dans les comptes) ;
  - `Échap` ou ✕ vident le filtre ;
  - `Entrée` ou `↓` passent au premier élément.
- Instantané même sur un dossier de 7 500 éléments, y compris avec un masque compliqué.
