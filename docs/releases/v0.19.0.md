CyberArkTerm devient **ZillaTerm**, avec une nouvelle icône.

- **Nouveau nom** : `ZillaTerm.exe`, titres des fenêtres, guide et README. Rien ne change dans l'utilisation.
- **Réglages repris** : au premier démarrage, le dossier `%APPDATA%\CyberArkTerm` (réglages, « Mes serveurs », coffre local, historique des transferts, journal de l'accès d'urgence) est copié dans `%APPDATA%\ZillaTerm`. L'ancien dossier est gardé : supprimez-le, avec `CyberArkTerm.exe`, une fois ZillaTerm adopté.
- **Compatibilité** : un fichier `CyberArkTerm.env.json` à côté de l'exécutable est encore lu (le nouveau nom est `ZillaTerm.env.json`) ; les listes partagées restent lisibles par les deux versions ; les mots de passe maîtres du coffre local restent accessibles ; les deux versions ne s'ouvrent pas en même temps.
- **Mises à jour** : cette version est publiée sous les deux noms d'archive (`ZillaTerm-…` et `CyberArkTerm-…`, même contenu), pour que les anciennes versions la proposent ; elle reconnaît le dépôt sous son ancien et son nouveau nom.
- **Ancien dossier temporaire** (`%TEMP%\CyberArkTerm`) : vidé au fil des démarrages (fichiers de plus d'un jour).
